---

Mostrá el estado actual del proyecto de forma concisa:

1. Leé `PROJECT_STATE.md`, `docs/roadmap.md` y `bootstrap.config.json` (del **directorio actual**; si no existen, decí que es una startup nueva y sugerí `/new-startup`).
2. Reportá: fase actual, hitos completados, próximo paso y riesgos abiertos.
3. Indicá qué features están en curso y cuáles bloqueadas.
4. Verificá salud del kit: versión (`kitVersion`), MCP disponibles, y si hay env vars faltantes (`NEON_API_KEY`, `GITHUB_TOKEN`).
5. Cerrá con 3 líneas: dónde estás, qué sigue, qué necesitás del usuario.

No modifiques archivos salvo actualizar `PROJECT_STATE.md` si estaba desactualizado.
